🚕 Taxi Data Analysis and Visualization
📌 Project Overview

This project focuses on analyzing taxi trip data using Python libraries such as Pandas, Matplotlib, and Seaborn. The goal is to clean raw taxi data, handle missing values, explore travel patterns, and create meaningful visualizations to understand fare distribution, trip distances, payment methods, and customer behavior.

The project uses the built-in Taxis Dataset available in Seaborn.

🎯 Project Objectives
Load and explore the taxi dataset.
Identify and handle missing values.
Perform data cleaning and preprocessing.
Analyze taxi fares and trip distances.
Explore customer payment preferences.
Visualize taxi trip patterns using Matplotlib and Seaborn.
Identify relationships between numerical variables.
